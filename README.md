# InterviewMentor-AI

## Overview

InterviewMentor-AI is an AI-powered mock interview assistant built using LangChain, LangGraph, and Gemini 2.5 Flash. The application conducts interactive interview sessions, evaluates candidate responses, asks contextual follow-up questions, and provides personalized feedback to help users improve their interview performance.

Unlike traditional chatbots, InterviewMentor-AI maintains conversation context using LangGraph's InMemorySaver, enabling realistic multi-turn interview experiences.

---

## Features

- Interactive mock interviews
- Personalized interview feedback
- Context-aware follow-up questions
- Multi-turn conversation support
- Session memory using InMemorySaver
- Gemini-powered response generation

---

## Unique Features

### In-Memory Context Retention

The application uses LangGraph's InMemorySaver to preserve conversation history throughout the interview session.

Benefits:

- Remembers previous answers
- Generates contextual questions
- Simulates real interviewer behavior
- Maintains interview flow
